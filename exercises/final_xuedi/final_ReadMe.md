# URSP688Y Final Project

## Project Title
Do Neighborhoods with Higher Housing Burden Also Have Higher Crime Rates?

## Study Area
Prince George’s County, Maryland

## Main File
final_xuedi.ipynb

## Data
- ACS 2020–2024 tract-level data
- PGPD 2024 crime incident data
- Census tract shapefiles

## Methods
This project uses Python, Pandas, GeoPandas, and spatial analysis to examine relationships between renter housing burden and crime rates at the census tract level.

## Note
The crime dataset already includes geographic coordinates, so this project converts coordinates into spatial point data instead of performing address geocoding.
